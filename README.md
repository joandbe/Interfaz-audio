# Interfaz-audio

# Sintetizador Max MSP9

Diseño de interfaz sonora interactiva con controles dinámicos para edición, modulación y procesamiento digital de señales (DSP).

## Descripción
Proyecto enfocado en la síntesis y manipulación de audio digital. Ofrece una interfaz de usuario minimalista para modificar parámetros clave de síntesis (osciladores, envolventes ADSR, filtros y modulaciones) en tiempo real.

## Tecnologías y Herramientas
* **Max/MSP (Max 9) / Web Audio API:** Motor de procesamiento digital de señales (DSP).
* **p5.js / JavaScript:** Interfaz de usuario personalizada e integración de controles interactivos.

## Funcionalidades
* Controles dinámicos para parámetros de audio (frecuencia, ganancia, resonancia).
* Visualización en tiempo real de la forma de onda generada.
